# Mock interviews

Run these alone or with a friend. A friend reads the questions and times you. Alone: set a timer, answer aloud, record, then check against the answers in each round. Question IDs link to the round files.

## How to score

For each question: 0 = missed, 1 = partly, 2 = strong (correct, simple, includes mechanism or example). Add up the points.

| Score | Meaning |
| --- | --- |
| 85 percent or more | Ready for this round |
| 65 to 84 percent | Review the missed topics and retry in 3 days |
| Under 65 percent | Re-read the lessons, then retry in a week |
