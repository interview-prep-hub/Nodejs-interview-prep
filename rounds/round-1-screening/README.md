# Round 1: Screening and Fundamentals

Usually 30 to 45 minutes, with a recruiter-technical or a first engineer call. The goal is to check that you know the basics and can explain them clearly. Short, confident, correct answers win this round.

## What is tested

- Core Node.js ideas: what it is, single thread plus non-blocking I/O, modules, npm.
- JavaScript basics: scope, closures, `this`, equality, array methods.
- Async basics: callbacks, promises, `async/await`, error handling.
- Communication: can you explain it simply in under a minute?

## How to practise alone

1. Study the lessons first: [01](../../lessons/01-introduction/README.md), [02](../../lessons/02-javascript-essentials/README.md), [03](../../lessons/03-modules/README.md), [04](../../lessons/04-npm-and-package-json/README.md), [07](../../lessons/07-async-javascript/README.md), [08](../../lessons/08-event-loop/README.md).
2. Read one question, close the answers, and answer ALOUD in 30 to 60 seconds. Recording yourself helps.
3. Open the answer. Score yourself: green (nailed it), yellow (partly), red (missed).
4. Redo reds the next day, then three days later.
5. Do the predict-the-output puzzles on paper before running them.

## Answer structure that works

1. One-sentence definition. 2. Why it exists. 3. A tiny example or a gotcha. Stop. Let the interviewer ask for more.

## Must-know list

Questions tagged `[Must-know]` come up in almost every screening. Be able to answer all of them without notes.
